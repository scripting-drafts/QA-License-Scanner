# Contributing

Contributions are accepted under the MIT License (inbound = outbound). Sign off
commits with the Developer Certificate of Origin 1.1 (`git commit -s`).

- Keep changes offline and dependency-free.
- Do not add network access, telemetry, or code execution to scanner modules.
- Add tests for new modules, policy rules, and validators.
- Run `npm test`.
- Do not include credentials, personal data, or host-specific paths in commits.
