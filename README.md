# QA License Scanner
Modular third-party license scanner and own-product compliance register.
```bash
./bin/qa-license-scanner scan /path/to/project --format md
./bin/qa-license-scanner validate legal/manifest.json
./bin/qa-license-scanner suite --root ..
./bin/qa-license-scanner rpc --workspace /path
```
